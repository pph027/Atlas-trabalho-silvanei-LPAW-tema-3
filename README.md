# ✳ Cosmic Atlas

Um catálogo interativo de objetos celestes desenvolvido como trabalho prático de Desenvolvimento Web, utilizando HTML5, CSS3 e JavaScript.

## Sobre o projeto

O Cosmic Atlas é uma página web temática sobre astronomia. Seu objetivo é apresentar objetos e fenômenos espaciais em um catálogo interativo, com uma interface inspirada em arquivos científicos futuristas.

## Funcionalidades

- Catálogo de objetos astronômicos
- Busca em tempo real
- Filtros por categoria
- Sistema de favoritos
- Salvamento dos favoritos com localStorage
- Modal de informações detalhadas
- Contador dinâmico de objetos
- Atalho de teclado Ctrl + K
- Layout responsivo para diferentes telas

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Estrutura do projeto

- index.html — estrutura da aplicação
- style.css — estilos e responsividade
- script.js — lógica e interatividade

## Como executar

Baixe os arquivos e abra o index.html em um navegador.

## Publicação

O projeto pode ser publicado gratuitamente usando o GitHub Pages.
